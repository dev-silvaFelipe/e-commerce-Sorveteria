Como construí a vitrine

Este projeto foi desenvolvido como um exercício de e-commerce estático, aplicando o conceito de headless commerce em miniatura. Toda a interface é construída com HTML, CSS e JavaScript, sem o uso de frameworks. Os produtos são carregados dinamicamente a partir de um arquivo products.json, simulando o consumo de uma API real. Isso separa completamente o conteúdo (dados) da apresentação (interface), tornando o projeto modular, escalável e fácil de manter.
